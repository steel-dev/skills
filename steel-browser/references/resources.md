# Resources for ongoing Steel work

Start with the installed CLI's `--help` and this skill's bundled references.
Use these links when the task needs more depth; do not fetch every resource for
every browser action.

- [Setup](https://setup.steel.dev/install.md): install, authorize, and load skills.
- [CLI guide](https://docs.steel.dev/overview/steel-cli): current browser and API-tool workflows.
- [Versioned v0.5.0 reference](https://github.com/steel-dev/cli/blob/v0.5.0/docs/cli-reference.md): exact command/flag reference for this baseline.
- [Steel docs](https://docs.steel.dev): sessions, profiles, files, CAPTCHA, proxies, and authenticated sites.
- [API reference](https://steel.apidocumentation.com/api-reference): REST contracts when CLI diagnostics are insufficient.
- [Cookbook](https://github.com/steel-dev/steel-cookbook): runnable SDK/application examples; load `steel-developer` for reusable code.
- [Skills catalog](https://github.com/steel-dev/skills): install/load `steel-session-debugging` or `steel-reliability` when their specialist guidance is needed.
- [Dashboard](https://app.steel.dev): sessions, usage, and account settings.
- [Support](https://discord.gg/steel-dev) and [CLI issues](https://github.com/steel-dev/cli/issues): report a reproducible problem with secrets removed.
